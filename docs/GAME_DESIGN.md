# 게임 설계

## 목표

스테이지마다 열쇠를 얻어 문을 열고 들어가면 다음 스테이지로 넘어간다.
제한 시간이 다 되거나 적에게 닿으면 목숨을 하나 잃고 그 스테이지를 처음부터 다시 한다.
목숨은 3개로 시작하고, 50스테이지를 모두 깨면 엔딩이다. 스테이지는 다섯 장(1~12, 13~22, 23~32, 33~42, 43~50)으로 나뉘고, 뒤로 갈수록 적과 함정이 늘어난다.

## 조작

| 동작 | 터치 | 키보드 |
|---|---|---|
| 이동 | 방향 패드 ◀ ▶ | ← → / A D |
| 웅크리기 | 방향 패드 ▼ | ↓ / S |
| 점프 | 점프 | Z, Space, ↑ |
| 마법 | 마법 | X |
| 불꽃 | 불꽃 | C |
| 일시정지 | 오른쪽 위 II | P, Esc |

- **마법**: 바로 앞 칸이 비어 있으면 돌 블록을 만들고, 돌 블록이 있으면 부순다.
  단단한 벽(청회색)은 부술 수 없다. 마법이 닿을 칸은 보라색 모서리로 표시된다.
- **웅크려 마법**: 한 칸 아래(발 앞)를 노린다. 구덩이 위로 다리를 놓을 때 쓴다.
- **기어가기**: 웅크린 채 방향을 짧게 누르면 방향만 바뀌고, 계속 누르면 걷기의 5분의 1 속도로 기어간다.
- **박치기**: 아래에서 돌 블록에 머리를 부딪치면 금이 가고, 두 번째에 깨진다.
- **점프**: 높이가 고정이다. 두 칸 높이까지 오를 수 있고, 같은 높이라면 세 칸 너비까지 건넌다.

## 적

| 적 | 맵 글자 | 움직임 | 쓰러뜨리기 |
|---|---|---|---|
| 고블린 | `g` | 바닥을 걷다 벽에서 돌아선다. 낭떠러지에서는 떨어진다 | 불꽃 |
| 오우거 | `O` | 고블린처럼 걷지만 앞을 막은 돌 블록을 잠깐 뒤 부순다 | 불꽃 |
| 위습 | `w` | 가로로 날다 부딪힌 돌 블록을 부수고 돌아선다 | 불꽃 |
| 스파크 | `s` | 블록 표면을 오른손으로 짚고 따라 돈다 | 불꽃 |
| 가고일 | `<` `>` | 제자리에서 바라보는 쪽으로 불을 뱉는다. 돌 블록이 막는다 | 불꽃 |
| 거울 | `M` `m` | 고블린(`M`)이나 위습(`m`)을 계속 불러낸다. 동시에 3마리까지 | 없음 |

## 아이템

| 아이템 | 맵 글자 (블록 속에 숨길 때) | 효과 |
|---|---|---|
| 열쇠 | `K` (`k`) | 문이 열린다. +1000 |
| 보석 | `$` (`1`) | +500 |
| 불꽃 항아리 | `j` (`2`) | 불꽃 +1 (최대 5) |
| 모래시계 | `h` (`3`) | 시간 +20초 |
| 종 | `b` (`4`) | 요정이 나와 위로 날아간다. 잡으면 목숨 +1 |
| 룬 | `r` (`5`) | +2000. 아래 "룬과 비밀 스테이지" 참고 |

남은 시간 1초마다 10점이 보너스로 붙는다.

## 룬과 비밀 스테이지

- 일반 스테이지 50개에는 룬이 하나씩 있다. 보이는 곳(`r`)에 있거나 돌 블록 속(`5`)에 숨어 있다.
  룬을 먹고 **그 스테이지를 깨야** 모은 것으로 기록된다.
- 한 장의 룬을 모두 모으면 그 장의 비밀 스테이지가 열린다. 비밀 스테이지는 번호(1~50)에
  끼지 않고 스테이지 고르기 화면 아래 "비밀 스테이지" 줄(S1~S5)에서 따로 고른다.

  | 장 | 일반 스테이지 | 비밀 스테이지 |
  |---|---|---|
  | 1장 | 1~12 | S1 메아리의 방 |
  | 2장 | 13~22 | S2 스파크 낙수 |
  | 3장 | 23~32 | S3 가고일의 시련 |
  | 4장 | 33~42 | S4 거울 미로 |
  | 5장 | 43~50 | S5 멀린의 시험 |

- 룬 10개마다 게임을 시작할 때 목숨 +1, 불꽃 +1 (50개면 목숨 8, 불꽃 5로 시작).
- 비밀 스테이지 다섯 개를 모두 깨면 진짜 엔딩이다.

규칙 계산은 `src/progression.ts` 에 모여 있다. 장 구분은 `src/game/levels.ts` 의 `CHAPTERS`,
비밀 스테이지 맵은 같은 파일의 `SECRET_LEVELS` 에 있다.

## 이름과 기록

- 처음 실행하면 이름을 정한다. 어떤 언어든 되고 12글자까지다. 로그인은 없고 이름은 그 기기에만 저장된다.
- 이름마다 기록이 따로다. 새 이름을 넣으면 1스테이지부터 새로 시작하고, 같은 이름을 다시 넣으면 이어서 한다.
- **백업 코드**: 타이틀의 "백업 코드"에서 기록을 글자 한 줄로 복사해, 다른 기기의 같은 화면에
  붙여 넣으면 옮겨진다. iPhone 에서 Safari 로 하던 기록을 홈 화면 앱으로 옮길 때도 쓴다.
  형식과 검사 방법은 `src/backup.ts` 에 있다.
- 이름 기능 전의 기록(`merlins-key:v1`)은 처음 등록하는 이름이 이어받는다.

## 스테이지 공개 일정

| 묶음 | 스테이지 | 열리는 때 |
|---|---|---|
| 1 | 1~30 | 처음부터 |
| 2 | 31~50 | 30스테이지를 깬 즉시 |
| 3~ | 51~70, 71~90, … (20개씩) | 아래 두 조건을 모두 채웠을 때 |

1. 지금 열린 묶음을 끝까지 깼다.
2. 지금 묶음이 열린 지 7일이 지났다. 지금 묶음의 룬을 모두 모았으면 3일(4일째).
   3일이 지난 뒤에 룬을 다 모았다면 다 모은 순간.

쉬는 동안 묶음이 쌓이지 않는다. 한 달을 쉬어도 다음 묶음 하나만 "지금 묶음을 다 깨면 바로 열리는"
상태로 기다린다. 아직 만들지 않은 묶음은 "준비 중"으로 보인다.

시각은 기기 시계가 아니라 GitHub Pages 응답의 Date 헤더(서버 시각)로 계산한다(`src/clock.ts`).
기기 시계를 앞으로 돌려도 열리지 않는다. 오프라인이면 마지막으로 확인한 서버 시각에서 멈춘다.
규칙은 `src/release.ts`, 시험은 `scripts/test-logic.mjs` 에 있다.

## 스테이지 만들기

`src/game/levels.ts` 에 15 × 12 글자 배열로 적는다. 바깥 테두리 벽은 엔진이 두른다.
고친 뒤에는 두 가지를 확인한다.

```bash
npm run check                                   # 맵 점검, 무작위 시뮬레이션, 저장된 길 재생
node scripts/solve-levels.mjs 5                 # 5스테이지의 길을 탐색으로 찾기
node scripts/solve-levels.mjs --run 5 walk-R …  # 동작을 하나씩 실행하며 위치 확인
```

`solve-levels.mjs` 는 진짜 엔진에 "한 칸 걷기, 점프, 마법" 같은 큰 동작을 이어 붙여
문까지 가는 길을 찾는다. 적은 빼고 돌리므로 "지형상 깰 수 있는가"만 보장한다.
탐색이 복잡한 스테이지는 못 찾을 수 있는데, 그때는 `--run` 으로 손수 길을 짠다.

일반 스테이지는 룬까지 먹고 문에 들어가야 성공으로 친다. 비밀 스테이지는 `S1`~`S5` 로 부른다.

확인한 길은 `scripts/routes.json` 에 둔다. `npm run check`(빌드 때 함께 돈다)가 이 길을
다시 따라가 보므로, 물리나 맵을 고쳐서 깰 수 없게 된 스테이지가 있으면 빌드가 멈춘다.
맵을 바꿨다면 그 스테이지의 길도 새로 찾아 `routes.json` 을 고친다.

스테이지 이름과 힌트는 `src/i18n.ts` 의 `stageN`, `hintN` 키에 영어·한국어로 함께 넣는다.

## 구조

```
src/
  main.ts              화면 흐름, 게임 루프, HUD
  i18n.ts              영어·한국어 문구와 언어 결정
  input.ts             터치 패드·키보드 → 프레임 입력
  audio.ts             Web Audio 효과음
  storage.ts           진행 기록 (localStorage)
  progression.ts       룬 규칙: 비밀 스테이지 열림, 시작 보너스, 진짜 엔딩
  release.ts           스테이지 공개 일정 (묶음, 7일·3일 규칙)
  clock.ts             서버 시각 (GitHub Pages Date 헤더)
  names.ts             이름 다듬기 (정규화, 길이 제한)
  backup.ts            백업 코드 만들기·읽기
  install.ts           홈 화면 설치 안내 (iOS·Android 판별)
  game/world.ts        규칙과 물리 (DOM 없음, Node 에서도 돈다)
  game/levels.ts       스테이지 데이터
  render/renderer.ts   캔버스 그리기
  render/sprites.ts    도트 그림
```
